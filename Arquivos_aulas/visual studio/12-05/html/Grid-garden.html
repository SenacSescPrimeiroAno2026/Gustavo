Grid Garden

Descrição

O jogo Grid Garden é um jogo online de programação html que utiliza o modo de programação "grid".

Como funciona:

Durante 28 níveis, você deverá utilizar o código grid para regar cenoruras e eliminar ervas daninhas da plantação.

O que aprende?

Com o Grid Garden, você aprende a gerenciar linhas e colunas, posicionamento de itens e espaçamento.

Opiniâo pessoal

Eu achei esse jogo muito bom, fácil de entender e desafiador em um nivel balaceado.
Nota final: 10/10
