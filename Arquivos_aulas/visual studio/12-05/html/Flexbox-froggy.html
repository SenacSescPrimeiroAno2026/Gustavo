Flexbox-froggy


Descrição

Um jogo online que, durante 24 níveis, você deve ajudar sapos a chegar em suas vitórias-régias determinadas pela cor.

Como funciona

O usuário deve utilizar o conhecimento de css flexbox para alihar os sapos em seus devidos lugares.

O que aprende?

Esse jogo ensina as propriedadesde CSS flexbox, utilizando o Justify-content para alinhar os sapos.

Opinião Pessoal

Eu achei meio confuso no começo, mas depois começa a fazer sentido, mas a dificuldade é bem alta.
Nota final: 8/10
