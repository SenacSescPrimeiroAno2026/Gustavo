Jogos que ajudam no aprendizado de HTML

Nesse site, haverá uma breve apresentação sobre Jogos HTML.

O que são jogos HTML?

Jogos HTML são ferramentas online que podem ser usadas para aprimorar as suas habilidades de programação.Esses games são baseados, normalmente, em várias fases, adicionando mais complementos a cada problema resolvido, ficando mais difícil conforme o progresso.

Qual a importância deles?

Eles são importantes pois podem ajudar uma pessoa a entender um assunto que ela tinha dificuldades e se desafiar a conseguir vencer.
