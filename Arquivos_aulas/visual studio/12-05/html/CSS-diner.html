CSS-Diner



Descrição

O CSS Diner é um jogo de navegador onde o usuário deve passar por 32 niveis selecionando diferentes itens com propriedades distintas em uma especie de mesa de jantar.

Como funciona

O jogador deve utilizar o codigo css para selecionar corretamente os itens, utilizando classes, ids e nomes.

O que aprende?

O jogador aprende sobre o uso de seletores de tags, classes, ids, combinação ou hierarquia, e o uso de pseudo-classes.

Opinião pessoal

Eu acho que é um excelente meio de aprendizado, a dificuldade é balanceada e desafiadora.
Nota final: 9/10
