Flexbox Defense

Descrição

O Flexbox defense é um jogo estilo Tower Defense em que você deve usar o estilo de código de flexbox para vencer 12 hordas de inimigos.

Como funciona

Nesse jogo você utiliza dos seus conhecimentos sobre Flexbox para posicionar as suas formas de ataque onde elas são mais eficientes para derrotar os inimigos.

O que aprende?

Com esse jogo você consegue aprimorar suas habilidades com o Justify content, para saber melhor sobre posicionamento de atributos.

Opinião pessoal

É um jogo muito bom, muito divertido e desafiador.
Nota final: 10/10
